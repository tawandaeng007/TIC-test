หน้าแรกความรู้สุขภาพผิวเกี่ยวกับข้อมูลติดต่อ
← บทความทั้งหมดสุขภาพผิว

ทำไมการบีบสิวเองจึงเพิ่มปัญหาได้

การบีบหรือแกะสิวอาจดันสิ่งที่อยู่ภายในลงลึก ทำให้การอักเสบมากขึ้น และเพิ่มโอกาสเกิดแผลเป็น

สิ่งที่ดูเหมือนหัวสิวอาจไม่เหมือนกัน

จุดเล็กบริเวณจมูกอาจเป็นสิวอุดตันหรือสิวเสี้ยน ซึ่งมีองค์ประกอบต่างกัน การพยายามบีบทุกจุดให้หายจึงอาจรบกวนผิวโดยไม่จัดการสาเหตุ และไม่ใช่ทุกตุ่มบนใบหน้าจะเป็นสิว

แรงบีบไม่ได้ออกไปด้านนอกเสมอ

แรงกดอาจทำให้สิ่งภายในและการอักเสบกระจายลงลึก แทนที่จะออกจากผิวทั้งหมด จึงอาจบวม เจ็บ และเห็นเม็ดใหญ่ขึ้น การใช้เข็มหรือเล็บเพิ่มโอกาสบาดเจ็บและติดเชื้อ ไม่ควรเจาะหรือกรีดเอง

รอยดำกับแผลเป็นต่างกัน

รอยสีเข้มหลังอักเสบเป็นการเปลี่ยนของสีผิว ส่วนหลุมหรือรอยนูนเกี่ยวข้องกับโครงสร้างผิว การปล่อยให้สิวอักเสบซ้ำและการแกะอาจเพิ่มปัญหาตามมา การดูแลสิวที่กำลังอักเสบจึงสำคัญ ไม่ใช่รอจัดการรอยเพียงอย่างเดียว

เปลี่ยนจากการแกะเป็นการสังเกต

หลีกเลี่ยงการจับบริเวณนั้นซ้ำ ลดการส่องใกล้เพื่อหาจุดบีบ และทำความสะอาดอย่างอ่อนโยน หากตุ่มเจ็บลึก บวมมาก หรือเป็นซ้ำ ควรให้แพทย์ประเมิน การนำสิวออกโดยผู้รักษามีการเลือกชนิดสิวและวิธีที่เหมาะสม ไม่ใช่กดได้ทุกเม็ด

รอยที่ตามมา

นอกจากบวมและเจ็บแล้ว อาจเกิดการติดเชื้อหรือรอยสีผิวเปลี่ยน การมีอุปกรณ์ที่ดูสะอาดไม่ได้ทำให้การกดสิวทุกชนิดเหมาะกับการทำเอง

ทางเลือกที่ควรพิจารณา

หลีกเลี่ยงการจับหรือแกะบริเวณนั้น และขอคำแนะนำเมื่อมีสิวเจ็บลึกหรือเกิดซ้ำ การเอาสิวออกโดยแพทย์มีการเลือกวิธีและประเมินความเหมาะสมก่อน
