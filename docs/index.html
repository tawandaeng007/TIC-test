หัตถการ

รู้จักโบทูลินัมท็อกซิน: กลไกและข้อจำกัด

โบทูลินัมท็อกซินออกฤทธิ์ต่อการส่งสัญญาณระหว่างเส้นประสาทกับกล้ามเนื้อ จึงใช้ทางการแพทย์ในข้อบ่งใช้บางอย่าง รวมถึงริ้วรอยจากการขยับกล้ามเนื้อ

อ่านต่อ
สุขภาพผิว

เข้าใจฝ้า และเหตุผลที่ต้องดูแลต่อเนื่อง

ฝ้าเป็นความผิดปกติของสีผิวที่พบได้บนใบหน้า การควบคุมฝ้ามักต้องใช้เวลาและการดูแลต่อเนื่อง ไม่ควรคาดหวังว่าการรักษาครั้งเดียวจะป้องกันการกลับมาได้เสมอ

อ่านต่อ
ดูแลประจำวัน

อ่านฉลากกันแดดอย่างเข้าใจ

การป้องกันแสงแดดไม่ได้มีแค่การทาครีม เสื้อผ้า หมวก และการอยู่ในร่มช่วยลดการสัมผัสรังสีได้ด้วย

สุขภาพผิว

ดูแลผิวเป็นสิวโดยไม่รบกวนผิวมากเกินไป

ผิวเป็นสิวไม่จำเป็นต้องถูกขัดหรือล้างบ่อยเพื่อให้สะอาดที่สุด การดูแลที่รุนแรงอาจเพิ่มการระคายเคืองและทำให้ดูแลสิวยากขึ้น

อ่านต่อ
สุขภาพผิว

ทำไมการบีบสิวเองจึงเพิ่มปัญหาได้

การบีบหรือแกะสิวอาจดันสิ่งที่อยู่ภายในลงลึก ทำให้การอักเสบมากขึ้น และเพิ่มโอกาสเกิดแผลเป็น

อ่านต่อ
เครื่องมือทางการแพทย์

เลเซอร์กำจัดขน: ทำไมต้องประเมินสีผิวและเส้นขน

การตอบสนองต่อเลเซอร์กำจัดขนสัมพันธ์กับสีและความหนาของเส้นขน สีผิว บริเวณที่ทำ และชนิดเครื่องมือ จึงไม่ควรใช้แผนเดียวกันกับทุกคน

อ่านต่อ
การเตรียมตัว

เตรียมข้อมูลสุขภาพก่อนทำหัตถการ

การประเมินก่อนหัตถการเริ่มจากข้อมูลสุขภาพที่ครบถ้วน ไม่ใช่เพียงการเลือกตำแหน่งที่ต้องการดูแล
